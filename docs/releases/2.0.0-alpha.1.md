# CentralPDF 2.0.0-alpha.1

Primeiro pré-lançamento público da nova arquitetura CentralPDF 2.0, desenvolvida com Vite, React e TypeScript e voltada ao processamento local de documentos.

## Destaques

- Nova interface CentralPDF 2.0 publicada pelo GitHub Pages.
- Processamento local no navegador, sem envio dos documentos para o servidor da aplicação.
- Catálogo pesquisável com indicação clara de disponibilidade das ferramentas.
- Workspace com fila serializada de arquivos, validação, progresso, cancelamento e limpeza segura de recursos.
- Blob URLs criadas fora do render e revogadas corretamente.
- Runtime com PDF.js, pdf-lib e QPDF WASM empacotados localmente.
- Fontes padrão do PDF.js incluídas para funcionamento offline.
- Limite de segurança de 250 MB para saídas da conversão de PDF em imagens.

## Ferramentas nesta versão

### Disponíveis

- Juntar PDFs.
- Extrair texto de PDF.

### Experimentais

- PDF para imagens.
- Proteger PDF com senha e restrições.

### Planejada

- Comprimir PDF.

## Qualidade

- 219 testes aprovados em 19 arquivos no ciclo de entrega inicial.
- TypeScript typecheck e build de produção aprovados.
- Testes do servidor Go e verificação de reprodutibilidade do executável Windows.
- CI com catálogo legado de 34 ferramentas protegido contra dessincronização.
- GitHub Pages e artefatos do Release construídos a partir do aplicativo 2.0, não da interface legada 1.2.1.

## Observações de pré-lançamento

Esta é uma versão `alpha`. Algumas ferramentas ainda estão experimentais ou planejadas e podem mudar antes da versão estável 2.0.0. O aviso de chunks grandes no build é conhecido e será tratado posteriormente com divisão de código e carregamento sob demanda.

## Artefatos

- `CentralPDF_Web_Local_v2.0.0-alpha.1.zip`: aplicativo web local completo.
- `CentralPDF_Local_Server.exe`: servidor local para Windows.
- `CentralPDF_Web_Local_v2.0.0-alpha.1.sha256`: hashes SHA-256 dos artefatos.
