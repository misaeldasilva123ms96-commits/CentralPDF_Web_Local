# Notas de lançamento — Central PDF 1.0

A versão 1.0 encerra o ciclo de construção iniciado nas versões 0.x e estabelece uma base estável para uso regular.

## O que muda para o usuário

- A página inicial identifica claramente a versão estável e as 34 ferramentas.
- O primeiro acesso explica o fluxo de trabalho e a privacidade local.
- O botão **1.0** abre o autodiagnóstico e dá acesso às preferências de acessibilidade.
- A navegação por teclado foi ampliada.
- Erros técnicos recentes podem ser consultados e exportados em JSON.
- O navegador avisa antes de fechar uma sessão com trabalho aberto, quando permitido.

## O que permanece compatível

- As 34 ferramentas existentes.
- Resultados, fluxos, predefinições e favoritos.
- Projetos `.cpdf` cujos módulos existem nesta versão.
- Preparação offline e servidor local.

## Recomendação de implantação

Mantenha a versão 0.20 como backup até concluir um teste real da 1.0 com documentos pequenos, projeto `.cpdf`, OCR e um lote grande representativo do uso diário.
