# Testes da versão 0.13

## Juntar PDFs — compositor visual

1. Abra **Juntar PDFs**.
2. Arraste dois ou mais PDFs de uma vez para a área de trabalho.
3. Confirme que todas as páginas aparecem como miniaturas.
4. Arraste uma miniatura para outra posição e confirme a nova ordem.
5. Use os botões de girar de uma página e confirme a rotação da miniatura.
6. Exclua e duplique páginas individualmente.
7. Selecione várias páginas e aplique rotação ou movimentação em lote.
8. Arraste um novo PDF sobre uma miniatura já carregada. Ele deve ser adicionado ao final, sem remover os anteriores.
9. Gere o PDF e confira se a ordem exportada corresponde às miniaturas.

## Adição contínua de arquivos

Repita em cada ferramenta que aceita vários arquivos:

1. Arraste um arquivo inicialmente.
2. Arraste outro arquivo sobre a lista, sobre uma capa ou em uma área vazia da ferramenta.
3. Confirme que o novo arquivo foi acrescentado.
4. Arraste vários arquivos simultaneamente e confirme a quantidade total.
5. Tente adicionar novamente o mesmo arquivo; duplicatas idênticas não devem ser inseridas na lista de entrada.

## Organizar e Editar PDF

- Ao arrastar vários PDFs de uma vez, o primeiro abre como documento principal.
- Os demais são adicionados como novas páginas.
- Novos PDFs arrastados posteriormente também devem entrar como páginas, sem substituir o documento aberto.

## Dividir e Extrair

- Ambas as ferramentas agora aceitam vários PDFs.
- A mesma regra configurada é aplicada a cada documento.
- Quando houver vários resultados, o download deve ser entregue em ZIP.
