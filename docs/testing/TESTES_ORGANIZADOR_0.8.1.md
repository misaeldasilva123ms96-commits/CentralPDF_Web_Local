# Testes — Organizador aprofundado 0.8.1

1. Abra Organizar PDF e carregue um PDF com pelo menos 5 páginas.
2. Gire uma página para esquerda e outra para direita.
3. Duplique uma página individualmente.
4. Exclua uma página individualmente.
5. Use + em uma miniatura e adicione páginas 1-2 de outro PDF.
6. Adicione duas imagens como páginas.
7. Insira uma página A4 em branco antes e depois de uma página selecionada.
8. Selecione múltiplas páginas e gire em lote.
9. Duplique a seleção, mova ao início e ao fim.
10. Exclua a seleção e use Desfazer/Refazer.
11. Arraste páginas para alterar a ordem.
12. Abra a prévia ampliada.
13. Salve o PDF e confira ordem, rotações e conteúdo importado.
14. Confirme que o arquivo original não foi alterado.
