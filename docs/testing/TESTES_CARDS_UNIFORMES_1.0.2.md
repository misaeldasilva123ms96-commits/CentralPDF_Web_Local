# Testes — cartões uniformes da home (1.0.2)

## Objetivo
Validar a padronização visual dos cartões de ferramentas na tela inicial.

## Cenários validados

1. Todos os cartões usam a mesma largura na grade desktop.
2. Cartões com classe `featured` não ocupam mais duas colunas.
3. Altura visual dos cartões permanece uniforme.
4. Títulos longos são limitados e não quebram o layout.
5. Descrições longas são limitadas e preservam alinhamento entre cartões.
6. O comportamento mobile continua preservado.

## Resultado
Aprovado.
