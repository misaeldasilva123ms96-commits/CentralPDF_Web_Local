# Roteiro de testes — interface 0.12

## 1. Barra lateral no computador
1. Abra qualquer ferramenta.
2. Clique na seta localizada no cabeçalho do menu lateral.
3. Confirme que o menu passa a mostrar somente ícones.
4. Passe o mouse sobre os ícones e confira o nome da ferramenta.
5. Clique novamente ou pressione `F9` para expandir.

## 2. Painel de propriedades
1. Clique no botão do painel direito na barra superior.
2. Confirme que a área central aumenta.
3. Clique novamente para restaurar as propriedades.

## 3. Modo foco
1. Abra o módulo Editar PDF.
2. Pressione `Ctrl + Shift + F`.
3. Confirme que os painéis esquerdo e direito desaparecem.
4. Pressione novamente para restaurar o layout anterior.

## 4. Preferências
1. Abra o botão de preferências de layout.
2. Escolha a densidade compacta.
3. Desative o guia contextual.
4. Clique em Aplicar.
5. Troque de ferramenta e confirme que a preferência foi mantida.
6. Use Restaurar padrão para desfazer as personalizações.

## 5. Celular
1. Abra uma ferramenta em uma tela pequena.
2. Toque no botão do menu lateral.
3. Confirme que o menu desliza pela esquerda.
4. Toque na área escurecida fora do menu para fechar.
5. Abra novamente e escolha outra ferramenta; o menu deve fechar automaticamente.

## 6. Regressão
- Verifique busca, seleção de ferramenta e upload.
- Abra Organizar PDF e Editar PDF.
- Confirme que os controles de transformação da versão 0.11 continuam presentes.
- Teste os atalhos do editor e a exportação com uma cópia pequena.
