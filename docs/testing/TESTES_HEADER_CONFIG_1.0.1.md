# Testes — cabeçalho com botão Configurações (1.0.1)

## Objetivo
Validar a reorganização do cabeçalho da Central PDF & Imagem, concentrando ações secundárias em um menu único.

## Cenários validados

1. O botão **Configurações** aparece no topo ao lado do indicador de processamento local.
2. Ao clicar, o painel exibe os grupos:
   - Projetos e sistema
   - Continuidade
   - Qualidade da versão
3. Os botões abaixo foram movidos para dentro do painel e continuam funcionais:
   - Projetos
   - Processos
   - Sistema
   - Resultados
   - Fluxos
   - Predefinições
   - Qualidade 1.0
4. O clique fora do painel fecha o menu.
5. A tecla **Esc** fecha o menu.
6. O cabeçalho principal permanece mais limpo e sem os grupos antigos visíveis fora do menu.
7. O painel funciona em layout desktop e responsivo.

## Resultado
Aprovado.
