# Roteiro de testes 0.17

1. Compare dois PDFs idênticos e confirme zero diferenças relevantes.
2. Altere uma palavra em uma cópia e confirme diferença textual.
3. Altere uma imagem e confirme diferença visual.
4. Compare arquivos com números de páginas diferentes.
5. Marque manualmente uma área e exporte o PDF censurado.
6. Pesquise uma palavra e revise as caixas criadas.
7. Copie texto da área censurada no resultado: o conteúdo original não deve existir.
8. Abra o relatório JSON e confira hashes e páginas reconstruídas.
9. Teste o modo reconstruir todas as páginas.
10. Confirme integração com Resultados e Predefinições.
