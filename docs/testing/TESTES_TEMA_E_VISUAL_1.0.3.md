# Testes — tema e refinamento visual (1.0.3)

## Objetivo
Validar a nova camada visual e o seletor de tema claro/escuro dentro de Configurações.

## Cenários validados

1. O painel **Configurações** exibe a seção **Aparência**.
2. Os botões **Tema claro** e **Tema escuro** alternam a interface.
3. A preferência fica salva no navegador local.
4. O tema escuro altera topo, home, cards, áreas de trabalho, dialogs e painel de configurações.
5. O tema claro continua funcional após alternância.
6. O menu de configurações permanece aberto ao escolher um tema.
7. A aplicação continua carregando normalmente com o último tema escolhido.

## Resultado
Aprovado.
